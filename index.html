※ This project is different from the Chrome extension Scratch Addons.

スクラッチアドオンとは？

スクラッチアドオンは、 Scratchの見た目を自由に変えられるようにした Scratch向けのModです。

使い方

よくある質問

共有マークを押して、 「Scratch Addons」を選択しましょう。
許可確認画面では「許可」を押してください。

注意

Scratch上では、 Scratch Addonsについて 言及・宣伝しないでください。

詳しくは Scratch Teamの方針 をご覧ください。
